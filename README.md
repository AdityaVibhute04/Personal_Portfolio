# Aditya Arjun Vibhute — Engineering Portfolio v1.2

Static academic/engineering portfolio for GitHub Pages. No npm, framework, database, or build step is required.

## What is included
- `index.html` — professional homepage and featured thesis
- `projects.html` — curated major projects with search/filtering
- `archive.html` — chronological coursework record
- `course-en110.html`, `course-ee790.html` — course collections
- `project-001.html` … `project-011.html` — detailed project pages
- `assets/images/` — website visuals and cleaned technical figures
- `assets/reports/` — submitted project/thesis PDFs
- `assets/source/` — source archives where available
- `assets/resume/` — current resume PDF and LaTeX source

## Deploy
Copy the **contents of this folder** to the root of the GitHub repository and push them with Git/Git Bash. GitHub Pages should serve the `main` branch from `/ (root)`.

See `DEPLOY_GITHUB.md` for the exact update commands.

## Privacy note
The IIT Bombay transcript is not included. The EN110 residential electricity-bill submission is also intentionally excluded from the public package because it may contain utility/personal information. Review public PDFs before publishing if you want to remove names, signatures, stakeholder details, phone numbers, or other personal material.

## Maintenance
The site intentionally remains plain HTML/CSS/JS. New projects can be added without a framework or build system. Keep the `assets/` directory structure unchanged so report, image, resume, and source-file links continue to work.
